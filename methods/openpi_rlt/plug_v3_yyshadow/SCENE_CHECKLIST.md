# plug_v3_yyshadow 场景冻结清单

本清单只用于现场确认和采集参考证据，不启动训练或 RLT。

## 机械与场景

- [ ] 右夹爪夹持插头的深度做实体标记。
- [ ] 插头绕夹爪轴的方向做实体标记。
- [ ] 排插方向和基准位置做实体标记。
- [x] 机械臂关键阶段起始pose使用`all --pose plug2`。
- [x] 中臂相机pose使用`mid --pose plug2`。
- [x] 左臂在关键阶段固定，不参与策略动作、proprio或训练。
- [ ] 工作区内没有新增障碍物或松动线缆。

## 相机

- [x] 训练和推理使用mid固定相机、left臂相机与right臂相机。
- [ ] mid/left/right设备序列号与topic对应关系确认。
- [ ] 三个相机支架锁紧，实验批次内不再调角度。
- [ ] 三路画面均持续刷新，没有静止帧。
- [ ] 实测每路原始频率不低于25 Hz。
- [ ] 三路帧时间偏差不超过120 ms。
- [ ] 读回并记录`plug2`保存的三路标准起始画面路径与哈希。

## 场景分布

- [ ] 确定 nominal 排插位置编号。
- [ ] 确定少量训练位置编号及各自采样比例。
- [ ] 确定不进入训练的 held-out 位置。
- [ ] 所有位置均使用实体标记或夹具复现。
- [ ] 第一批不改变排插角度、相机外参或插头夹持方式。

## 标签

- [ ] `success`：插头真实落座。
- [ ] `failure`：录制有效但终止时未落座。
- [ ] `aborted`：故障、坏帧、错误复位、操作员取消，不进入正式 replay。
- [ ] 发生过任何 HIL 的成功只能记作 `hil_success`，不能计入自主成功。

全部完成后，将 `scene_contract.json` 的现场字段填入，设置：

```json
"reference_status": "captured"
```

然后运行：

```bash
python3 validate_contract.py --require-scene-reference
```
